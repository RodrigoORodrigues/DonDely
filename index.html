Supabase Multi-Tenant Architecture

🔒 ISOLAMENTO ATIVO

Cada empresa cadastrada opera sob um Tenant ID isolado (company_id). O banco Supabase conta com Row Level Security (RLS) ativo em todas as tabelas (companies, products, orders, settings, coupons), garantindo zero cruzamento de dados entre empresas.

Empresa Ativa Atual - -
Segurança e RLS ✓ RLS Restrito por Empresa company_id Foreign Key Cascade
Como conectar suas chaves do Supabase no servidor:
  1. Crie seu projeto no console do Supabase.com.
  2. Execute o script SQL fornecido no SQL Editor do Supabase.
  3. Defina as variáveis SUPABASE_URL e SUPABASE_ANON_KEY (ou SUPABASE_SERVICE_ROLE_KEY).
  4. O servidor e o app gerenciam automaticamente todo o roteamento isolado por empresa.
